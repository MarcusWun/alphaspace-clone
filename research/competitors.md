# Competitor Landscape

## Tier 1: Direct Competitors

### AlphaSpace (Yahoo Finance) — the reference product
- $39.99/mo (Gold)
- Launched May 19 2026
- Drag-and-drop canvas, AI assistant (Yahoo Scout), persistent workspaces
- Yahoo Finance's 150M daily user base as distribution
- **Weakness:** Locked to Yahoo Finance data; no self-hosting; no API access

### Koyfin
- $49/mo (Pro)
- Custom dashboards, global equities, analyst estimates, financials
- Stock comparison graphs, data viz, filings, market news
- Used by professionals ("comparable to Bloomberg")
- **Weakness:** Less customizable canvas; AI features limited; no video

### Bloomberg Terminal
- $27,000/yr per user
- The gold standard — real-time everything, messaging, analytics
- **Weakness:** Price excludes retail entirely

## Tier 2: Partial Competitors

### Benzinga Pro
- $197/mo
- Direct news feed, alerts, stock screener, chat room
- **Weakness:** News-focused; weak charting and workspace customization

### Finchat
- Free tier + paid
- AI-first: 25 AI prompts/mo free, global coverage, KPI data
- **Weakness:** Limited charting; narrow focus

### AlphaSense
- Enterprise pricing ($50K+/yr)
- AI document search, earnings transcripts, filings
- **Weakness:** Not for retail; no real-time trading data focus

### TradingView
- Free – $60/mo
- Excellent charting, social ideas, pine script
- **Weakness:** Not a research workspace; no fundamentals depth; no AI assistant; no drag-drop canvas

## Key Differentiation Opportunities for Clone
1. **Self-hosted / open-source option** — no comparable exists
2. **More aggressive AI** — build views from natural language with better LLMs
3. **Panel linking system** — context propagation between widgets
4. **Custom data sources** — allow user to bring their own data feeds
5. **Price** — self-hosted means no recurring subscription beyond API costs
